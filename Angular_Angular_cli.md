# Angular / Angular CLI

## Angular

Angular est un framework JavaScript.
Il sert à créer des applications web modernes (rapides, dynamiques, organisées), souvent appelées SPA (Single Page Applications).

👨‍💻 Il utilise TypeScript (un sur-ensemble de JavaScript) et permet de :

- Découper l’appli en composants

- Gérer facilement l’affichage, la logique, la navigation

- Structurer proprement le code pour des projets complexes
